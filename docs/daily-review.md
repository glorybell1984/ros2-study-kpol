# 매일 복습 루틴 (약 60~90분)

제일 효과가 큰 건 **코드를 보지 않고 다시 짜 보는 것**이다.

| 순서 | 할 일 | 시간 |
|---|---|---|
| ① 백지 복습 | 아무것도 보지 않고 오늘 배운 개념을 적고, 노드·토픽 연결도 그려 보기 | 10분 |
| ② 다시 짜기 | 수업 코드를 5분 훑고 **닫은 뒤** 처음부터 다시 작성 → `practice/<이름>/`에 올리기 | 30~40분 |
| ③ 하나 바꿔 보기 | 토픽 이름·주기·파라미터 중 하나를 바꾸고, 결과를 먼저 예측한 뒤 실행 | 10~15분 |
| ④ 막힌 곳만 찾아보기 | 막힌 부분만 영상 구간이나 공식 문서에서 확인 | 10분 |
| ⑤ 기록 | 노션 📖 매일 복습 기록에 한 줄, 막힌 것은 📒 오답노트에 | 10~20분 |

시간이 없는 날: 백지 복습 10분 > 다시 짜기 > 오답노트 > 문서 > 영상
